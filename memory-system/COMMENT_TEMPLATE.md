## 模块级 docstring 五要素

每个核心 `.py` 文件顶部应包含：

1. **职责**：本模块在记忆系统中的角色
2. **输入**：主要依赖的数据或调用方传入参数
3. **输出**：对外暴露的类型或副作用产物
4. **副作用**：磁盘写入、网络、全局状态等
5. **失败处理**：降级、回退、静默跳过等策略

## 示例

```python
"""
模块: memory_system_py.extractor
职责: 从会话轮次中抽取可长期保存的记忆候选。
输入: List[ConversationTurn]，可选 source 标记。
输出: List[MemoryRecord]（可能为空列表）。
副作用: 无；不直接写库，由 MemorySystem.ingest_session 负责持久化。
失败处理: 单句解析失败不影响其他句子；无匹配关键词时返回空列表。
"""
```

## 公共方法补充

对 `MemorySystem` 与各模块的 public 方法，在 docstring 中补充一行 `注释：` 说明行为边界。
